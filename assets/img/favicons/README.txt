Yanniezinha Fox Favicons

把以下文件复制到博客仓库：
assets/img/favicons/

需要覆盖：
- apple-touch-icon.png
- favicon.ico
- favicon.svg
- favicon-96x96.png
- web-app-manifest-192x192.png
- web-app-manifest-512x512.png

说明：
- favicon.png 和 fox-master-1024.png 是额外提供的母版/备用图。
- 不要删除或覆盖 Chirpy 项目原有的 site.webmanifest。
- favicon_old 一类文件只是备份，不参与网站显示，可以删除。
- 替换后提交并推送 GitHub；若仍显示旧图，请强制刷新或清除浏览器 favicon 缓存。
